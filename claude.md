# MakeMyMarrige — Claude Code Rules

- Read AGENTS.md and relevant docs before changes.
- Inspect existing code before implementing; reuse existing architecture.
- Treat approved decisions as authoritative; never invent requirements.
- Work from repository root using Git Bash and relative paths.
- Preserve all tracked and untracked changes.
- Implement only the requested scope.
- Prefer existing dependencies and patterns.
- Never expose, generate or print secrets/private keys without explicit authorization.
- Never weaken security to bypass configuration blockers.
- Run relevant tests, typecheck, lint and builds after changes.
- Fix verified failures; report environment-dependent blockers.
- Never commit, push, reset, clean or discard changes without permission.
- Batch independent safe operations; avoid repetitive approval requests.
- Final report: changes, tests, failures, blockers and next action.
- Do not claim success without evidence.
