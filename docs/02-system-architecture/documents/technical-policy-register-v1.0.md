## Decision boundary

The defaults above are recommendations for review, not approved requirements. Product-owner approval is required where the last column says yes. Security/operations review may additionally be required for implementation parameters. Keep `decision_status`, `implementation_status` and `release_status` separate in all downstream records. No item authorizes application implementation of a blocked contract or a provider integration.
